# Fact It - Roadmap

## Phase 1 - Browser Extension

Article
  ->
Extract
  ->
Normalize
  ->
AI
  ->
Validate
  ->
Fact It Bar

## Phase 2 - Evidence Engine

Claim
  ->
Search
  ->
Evidence
  ->
Source
  ->
Assessment
  ->
Citation

## Phase 3 - Community Platform

Users can:

- review
- challenge
- submit evidence
- add context
- evaluate AI analysis

## Phase 4 - Reputation

Independent reputation for:

- Source
- Author
- Contributor

## Phase 5 - Trust & Abuse

Potential abuse signals:

- spam
- fabricated sources
- bots
- coordinated manipulation
- vote manipulation
- repeated malicious submissions

Political or ideological orientation itself is NOT an abuse signal.
